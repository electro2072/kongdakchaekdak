## 화이트박스 — S1 구현 검토 (통과)

`frontend/src/navigation/AuthContext.tsx` + `services/secureStorage.ts` + `navigation/RootNavigator.tsx` 정독.
지시서 §C의 **logcat 3줄이 코드와 정확히 일치**하며, 실측에서 3줄이 각각 다른 케이스(S1-1 / S1-6)에서
서로 다르게 찍혔음 — 판정 방법 유효.

- 저장: `setAccessToken` → state + apiClient 주입 + `secureStorage.setItem('@kongdakchaekdak/accessToken', ...)`
- 복원(부팅 1회): 토큰 없음 → 조용히 종료 / 200 → `저장된 세션 복원 완료` / `status:0` → 세션 유지 / 그 외 → 폐기
- 로그아웃: state 정리 + `secureStorage.removeItem`
- `RootNavigator`: `isRestoring` 동안 `<ActivityIndicator>`만, 그 뒤 `isLoggedIn ? MainStack : AuthStack`

**console → logcat 전달 확인**: release 빌드에서도 `logger`(→`console.*`)가 `ReactNativeJS` 태그로 찍힘.
babel/metro에 `transform-remove-console` 없음.
