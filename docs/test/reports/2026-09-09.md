## 화이트박스 — S1 구현 검토 (통과)

`frontend/src/navigation/AuthContext.tsx` + `services/secureStorage.ts` + `navigation/RootNavigator.tsx` 정독.

1. **저장**: `setAccessToken(token)` → state + `apiClient` 주입 + `secureStorage.setItem('@kongdakchaekdak/accessToken', token)`.
2. **복원**(앱 시작 1회 `useEffect`):
   - 저장 토큰 없음 → `setIsRestoring(false)` 후 종료 (로그 없음 — S1-3/콜드스타트에서 실측 일치).
   - 있음 → `apiClient`에 주입 후 `getMe()`(`GET /api/auth/me`) 호출:
     - 200 → `logger.info('AuthContext', '저장된 세션 복원 완료')` + `isLoggedIn=true`
     - `ApiError.status === 0`(네트워크) → `logger.warn('...','세션 검증 실패(네트워크) — 세션 유지')` + 토큰 **유지** + `isLoggedIn=true`
     - 그 외(401 등) → `logger.warn('...','세션이 만료됨 — 저장된 토큰 폐기')` + `secureStorage.removeItem` + 로그인 화면
3. **로그아웃**: state 정리 + `secureStorage.removeItem`. `apiClient`의 401 핸들러에도 `logout` 등록(순서 비의존).
4. **저장소**: `react-native-encrypted-storage`(iOS Keychain / Android EncryptedSharedPreferences). 이전 키 `@konggdak/accessToken`(오타, AsyncStorage) → 새 키. 마이그레이션 없음 = 기존 로그인 단말은 1회 로그인 화면으로 떨어짐(의도).

→ 지시서 §C의 **logcat 3줄이 코드와 정확히 일치**. 판정 방법 유효.

**console → logcat 전달 확인**: release 빌드에서도 `logger`(→ `console.*`)가 `ReactNativeJS` 태그로 logcat에 찍힘.
실측: 게스트 진입 시 `I ReactNativeJS: [..][INFO][AuthContext] 로그인 완료 처리 (isLoggedIn=true)`.
babel/metro에 `transform-remove-console` 없음 → release에서도 info/warn 로그 살아 있음.

## 🚧 블로커 — S1-1 실행 불가 (사람 개입 필요)

지시서 **B-2**: "로그인 단계에서 사람의 개입이 필요하면 거기서 멈추고 사용자에게 요청. 임의로 우회하지 않는다."

- S1-1(및 S1-2·4·5·6·7)은 **실제 소셜 계정 로그인으로 세션을 먼저 만들어야** 시작 가능.
- 에뮬레이터 상태: Play Services 있음, 그러나 **등록된 Google 계정 0개** (`dumpsys account` → `Accounts: 0`).
  - Google 로그인 → 계정 추가 플로우 → **비밀번호 입력 필요** → 테스터가 자격증명 입력 불가(정책).
  - 카카오/네이버 → 웹뷰/앱에서 자격증명 입력 필요 → 동일.
- `adb`로 토큰을 EncryptedStorage에 직접 주입하는 우회는 Android Keystore 암호화라 불가.

### 사용자 요청 — 아래 중 하나

1. **(권장) 이 PC 에뮬레이터에서 직접 로그인**: 지금 `Pixel_7` 에뮬레이터가 로그인 화면에 있음.
   - Google이면 설정 → 계정 → Google 계정 추가 후, 앱에서 "Google로 시작하기".
   - 또는 "카카오로 시작하기" / "네이버로 시작하기"에서 로그인.
   - 로그인해서 하단 탭까지 들어가면 알려주세요 → 테스터가 S1-1~S1-7 로그 판정 이어서 수행.
2. **본인 실기기에서 S1-1만 수행**: 아래 명령을 본인 단말에서 실행하고 logcat 결과를 붙여주세요.
   ```
   adb shell am force-stop com.kongdakchaekdak
   adb logcat -c
   adb shell am start -n com.kongdakchaekdak/.MainActivity
   adb logcat -d -s ReactNativeJS:V | grep -E "저장된 세션 복원 완료|세션이 만료됨|세션 검증 실패"
   ```
   (로그인된 상태에서. `pm clear` 쓰지 말 것 — 앱 데이터 지워짐)
3. 지금 불가 시 → **S1-1 = 미검증(로그인 차단)**으로 확정, A표 #5 🟡 유지.
