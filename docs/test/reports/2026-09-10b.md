### BUG-20260910-b02  존재하지 않는 라우트·미지원 HTTP 메서드가 404/405 대신 500을 반환
- 심각도: **minor** (데이터 유출/기능 파손 아님. 단 에러 모니터링에 가짜 "서버 오류"가 쌓이고, FE가 라우팅 실수에 "오류가 발생했어요(오류번호)" 를 띄움)
- 영역: **backend**
- 상태: open
- **검증 환경**: 로컬 `./gradlew bootRun --spring.profiles.active=local` (H2) · 커밋 `dbe86cd`
- 재현 절차 (전부 500 `INTERNAL_SERVER_ERROR` + traceId):
  - `GET /api/users` (컬렉션 GET 매핑 없음 — G20에서 삭제) → 500

  - `POST /api/books/27` (해당 경로에 POST 없음) → 500
  - `DELETE /api/dashboard`, `PUT /api/users/9001/xyz` → 500
- 기대 결과: 404(no handler) / 405(method not supported)
- 실제 결과: `GlobalExceptionHandler`에 `NoHandlerFoundException`·`HttpRequestMethodNotSupportedException`·`NoResourceFoundException` 핸들러가 없어 catch-all `handleUnexpected(Exception)` → 500. 서버 로그: `org.springframework.web.HttpRequestMethodNotSupportedException: Request method 'GET' is not supported` → `GlobalExceptionHandler - 예상하지 못한 서버 오류`

## 8. §H — 연동매트릭스 A표 갱신 요청
