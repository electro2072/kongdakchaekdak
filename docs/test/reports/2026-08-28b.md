## 이슈

### FINDING-20260828-07  로그인 화면 브랜딩 미반영 (major)
- 영역: frontend · 상태: open
- `LoginScreen.tsx`:
  - 로고: `<BookOpen size={26} .../>` on `colors.p50`. 목업 v1.7은 이 자리를 **실제 앱 아이콘 배지**
    (쑥송편 그린 `#7D8F5D` 배경 + "콩닥"/"책닥" 두 줄 크림 텍스트)로 교체함.
  - 워드마크: `"독서 자랑"`. 목업 v1.6은 앱 이름 확정에 따라 **"콩닥책닥"**으로 교체함.
- `LoginScreen` docstring이 "Hi-Fi 목업 v1.3 기준"이라 명시 — v1.6/v1.7 변경(둘 다 2026-08-27)이 반영 안 됨.
- 영향: 앱의 첫 화면에 옛 임시 이름이 노출됨.
- 넘길 대상: reading-record-frontend-agent

### FINDING-20260828-08  책 등록 확인 화면(Frame 08.2) 미구현 (major)
- 영역: frontend · 상태: open
- `BookSearchScreen`에서 검색 결과를 고르면 `Alert.alert("책을 선택했어요…")` → `navigation.goBack()`.
  목업 Frame 08.2가 요구하는 **장르 선택(6칩) + 읽기 시작일 + "등록하기"** 단계가 없음.
- 영향: 책 등록 플로우가 "선택"에서 끊겨, 장르·시작일을 입력할 방법이 화면상 없음
  (`POST /api/books`는 `genre`/`startDate`를 받음 — 백엔드 계약과도 어긋남).
- 넘길 대상: reading-record-frontend-agent

### FINDING-20260828-09  BookSearchScreen 다크모드 미대응 + 스타일 불일치 (minor)
- 영역: frontend · 상태: open
- `backgroundColor: "#fff"` 하드코딩(테마 `colors.surface` 미사용) — 10개 화면 중 유일. 다크모드에서 흰 배경.
- 더불어 이 파일만 더블쿼트·다른 import 정렬 컨벤션(다른 화면은 싱글쿼트). 리팩터 대상.
- 넘길 대상: reading-record-frontend-agent

### FINDING-20260828-10  미구현 프레임 3개 (minor, 범위 이슈)
- Frame 02.1 일정 상세(일정 탭 카드/캘린더 탭 시 이동), Frame 04.1 그룹 관리·공유 이력,
  Frame 10 알림 목록(일정 탭 bell 아이콘 목적지) — 라우트 자체가 없음.
- `ScheduleScreen`의 `<Bell>`, `ShareScreen`의 그룹 영역에 진입점 미연결.
- 04.1은 `ShareScreen` docstring에 "이후 작업"으로 인지됨. 나머지 2개는 문서화도 안 됨.
- 넘길 대상: reading-record-frontend-agent (구현 우선순위는 PM/사용자 판단)

### FINDING-20260828-11  선택된 칩 색상 — 목업의 카테고리 포인트 컬러 미적용 (minor, 디자인 확인 필요)
- 영역: frontend (+ design 확인) · 상태: open
- `SignupScreen`/`ProfileEditScreen`의 관심분야 selected 칩이 전부 `colors.accentSolidBg`(그린).
  목업 Frame 01.1/05.2는 selected 칩에 칩별로 다른 색(예: 자기계발 `#e8929b` 분홍, 과학 `#efb94a` 치자)을 씀.
- 디자인 시스템 v1.2 changelog: "카테고리 구분용 포인트 멀티컬러를 관심분야 칩과 장르 비율 차트에 반영".
  다만 **어느 카테고리 → 어느 색** 매핑이 목업 마크업만으론 불명확(위치 기반인지 고정인지).
- 조치: design-agent에 "관심분야 6종 ↔ 포인트 컬러 매핑" 확정 요청 후 frontend 반영.
