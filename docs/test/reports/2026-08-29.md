  - 라이브: 가짜 토큰 `POST /api/auth/kakao`·`/google` → 여전히 401 `INVALID_CREDENTIALS`,
    isNewUser 리팩터로 인한 에러 경로 회귀 없음 ✅

    카카오 access token이 필요(이전 토큰 만료) — 화이트박스로 커버됨, 필요 시 사용자 토큰으로 재현.

```

```

```ts
if (result.isSuccess) {
  return result.successResponse.accessToken;   // ← successResponse가 optional
```
