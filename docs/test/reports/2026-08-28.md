## 이슈

### FINDING-20260828-05  다크 뉴트럴 램프 비단조 (minor)
- 영역: frontend · 상태: open
- `frontend/src/theme/colors.ts` `darkColors`: `n50:'#1e211b'` > `n100:'#1a1d17'` (n50이 더 밝음).
  다크 모드에서 n50은 램프의 가장 어두운 끝이어야 하는데 n100보다 밝다.
- 영향: n50/n100을 배경 위계로 쓰는 화면에서 위계가 미묘하게 반대로 나올 수 있음.
- 근거: design `color_chips.html`엔 다크 뉴트럴 램프의 명시적 10단계가 없어(주로 `d-surface-*`/`d-text-*` 토큰 사용) 프론트가 자체 확장한 값. 확장 시 순서를 놓친 것으로 보임.
- 넘길 대상: reading-record-frontend-agent

### FINDING-20260828-06  다크 앱 배경 토큰 부재 / 값 불일치 (minor)
- 영역: frontend · 상태: open
- design: `--d-surface-app: #181a14` (앱 바탕) ≠ `--d-surface-card: #242721` (카드). 두 단계가 구분됨.
- 프론트: `surface`(=#242721, 카드)만 있고 앱 바탕 전용 토큰이 없음. `RootNavigator`가
  `background: colors.n50`(#1e211b)로 대체 → design 의도(#181a14)보다 밝고, 라이트 모드도
  `n50`(#f6f7f3)을 배경으로 써서 design에 대응 토큰이 있는지 확인 필요.
- 제안: `appBackground`(또는 `surfaceApp`) 시맨틱 토큰을 추가하고 design 값(#181a14 / 라이트 대응값) 사용.
- 넘길 대상: reading-record-frontend-agent
