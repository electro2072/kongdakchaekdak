### BUG-03 상세 — `@Lazy`로는 안 됨
`gradle bootRun --args="--spring.profiles.active=local"` (AWS 자격증명 환경변수 없이) →
여전히 `APPLICATION FAILED TO START`:
```
Error creating bean 'bookPhotoController' → 'bookPhotoService' 생성자 파라미터 2 →
's3Presigner': Factory method threw NullPointerException: Access key ID cannot be blank.
  at com.bookflex.config.S3Config.s3Presigner(S3Config.java:40)
```
`@Bean @Lazy s3Presigner()` 만으로는 부족 — `BookPhotoService`가 **생성자 주입**으로
`S3Presigner`를 받기 때문에 컨텍스트 초기화 중 빈이 실제로 생성됨. 해소하려면:
- 주입 지점에도 `@Lazy` (`BookPhotoService(..., @Lazy S3Presigner presigner)`), 또는
- `S3Presigner`를 빈 자격증명으로 만들지 않도록 `DefaultCredentialsProvider`/지연 자격증명 사용, 또는
- 자격증명 없으면 `S3Presigner` 빈 자체를 조건부 생성(`@ConditionalOnProperty`) + 사용처에서 null 처리.

→ reading-record-backend-agent 재작업 필요. 그때까지 블랙박스 테스트는 더미 AWS env 워크어라운드 유지.

  → **201**, 응답도 소문자 직렬화(`"shareType":"book"`). `frontend/src/types/share.ts`(소문자)와 일치 ✅
