  `app-release.apk`(2026-08-31 빌드, 58.8MB, JS 번들 내장 = 단독 실행) 설치.

## 3. 이슈

### BUG-20260901-17 (major) — 서재 검색창 placeholder 한글 깨짐
- 영역: frontend · 상태: open
- `LibraryScreen`의 책 제목 검색 `TextInput` placeholder가 **"책 제목으로 검색"** 이어야 하는데
  화면에 **`섹 세ᅳ긐ᅳ노 검색`** 처럼 한글 자모가 분해되어 렌더됨 (조합 안 됨).
- 같은 화면의 다른 한글("읽고 있는 책", "최근순", 책 제목)과 `BookSearchScreen` 검색창
  placeholder("책 제목, 저자를 검색해보세요")는 **정상** → 이 `TextInput` placeholder 하나만.
- 추정: 그 `TextInput`에 적용된 `fontFamily`(Pretendard)가 Android에서 placeholder에 대해
  자모 조합을 못 하고 fallback, 또는 placeholder 문자열이 NFD(분해형)로 들어가 있음.
- ⚠️ 이 APK는 `5e25dbb`(한글 IME 조합 문자 버그 조치) **이전** 빌드 — 최신 빌드로 재확인 필요.
  같은 뿌리(한글 조합)일 수 있음.
- 넘길 대상: reading-record-frontend-agent

### OBS-20260901-18 (minor) — 책 검색 "검색" 버튼이 파란색 (테마 미적용)
- `BookSearchScreen`의 `SearchBar` 컴포넌트 "검색" 버튼이 앱 테마 그린(`p700`/`accentSolidBg`)이
  아니라 **머티리얼 기본 파란색**. `SearchBar.tsx`가 테마 시스템 이전 레거시 컴포넌트로 보임
  (`Button` 기본값 또는 하드코딩). 목업 Frame 08은 그린.
- 넘길 대상: reading-record-frontend-agent

### FINDING-11 재확인 — 관심분야 칩 색
- `ProfileEditScreen` 선택 칩이 전부 그린(소설·자기계발·과학 동일). 목업은 카테고리별 포인트 컬러.
- **단 이 APK는 `658bcb9`(디자인 6장르 고정색 전환) 이전 빌드.** Dashboard 도넛엔 이미
  소설=그린/에세이=핑크로 반영돼 있으므로, 칩도 최신 빌드에선 바뀌었을 수 있음 — 재확인 필요.
