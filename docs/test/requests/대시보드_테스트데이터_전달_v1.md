## 1. 무엇을 전달하나

**`docs/test/fixtures/dashboard-seed.sql`** (커밋 `307833b`) — 실행만 하면 됨.

| | |
|---|---|
| 유저 | `id=9001`, `nickname='리캡테스터'`, `social_provider='seed'` — 실제 소셜 계정과 안 겹침 |
| 완독 | **22권** — 6개 장르 전부(소설 최다), 완독 기간 2~30일, 페이지 132~690, `end_date`가 최근 12개월에 분포 |
| 진행중 | 3권 |
| 날짜 | 전부 `CURRENT_DATE` 상대값 → **언제 실행해도 "최근 12개월"**. 맨 위 `DELETE` 3줄이 먼저 지우므로 **재실행 가능** |
| 호환 | `INTERVAL '3' MONTH`(숫자에 따옴표) — H2(로컬) + MySQL 8(Railway) 둘 다 OK. `INTERVAL 3 MONTH`는 H2에서 syntax error |

## 2. 실행

### 로컬 (H2)
```
cd backend && gradle bootRun --args="--spring.profiles.active=local"
```
→ `http://localhost:8080/h2-console`
(JDBC URL `jdbc:h2:mem:kongdakchaekdak;MODE=MySQL`, user `sa`, 비번 없음)
→ `dashboard-seed.sql` 붙여넣고 실행.

### Railway (MySQL)
```
railway run mysql < docs/test/fixtures/dashboard-seed.sql
# 또는 railway connect 후 파일 실행
```

## 3. 조회 — ⚠️ JWT 시크릿 주의

**로컬 `gradle bootRun` 은 `backend/.env` 의 `JWT_SECRET` 을 읽어 쓴다** (`application.yml` 의
기본값 `please-change-...` 아님). 테스터도 이것 때문에 처음에 401 났음.

```bash
# 로컬
node docs/test/tools/mint-jwt.mjs 9001 "$(grep '^JWT_SECRET=' backend/.env | cut -d= -f2-)"

# Railway (Railway 환경변수 JWT_SECRET 사용)
node docs/test/tools/mint-jwt.mjs 9001 "<Railway의 JWT_SECRET>"
```

발급한 토큰으로:
```
GET /api/dashboard                 # 이번 달
GET /api/dashboard?period=quarter  # 이번 분기
GET /api/dashboard?period=year     # 올해
GET /api/dashboard?period=month&date=2026-07   # 특정 달 고정
```

## 4. 검증됨 (테스터가 로컬 H2 bootRun + 실제 `GET /api/dashboard` 호출, 2026-09-08)

| period | completedBookCount | totalPagesRead | genreRatios (도넛) | monthlyTrend (직전 6개월) | highlights |
|---|---|---|---|---|---|
| month (2026년 9월) | 6 | 1552 | 소설 50% / 에세이 33.3% / 자기계발 16.7% | 04~09: 2·2·3·2·2·6 | 최장 41일 / 최단 2일 |
| quarter (2026년 3분기) | 10 | 2912 | 소설 60% / 에세이 20% / 인문 10% / 자기계발 10% | 04~09: 2·2·3·2·2·6 | 최장 41일 / 최단 2일 |
| year (2026년) | 23 | 6528 | **6개 장르 전부** (소설 47.8% / 에세이 26.1% / 인문·자기계발 8.7% / 경제·경영·과학 4.3%) | 07~12: 2·2·6·0·0·0 | 최장 41일 / 최단 2일 |

- **tie-break** — 최장 완독 동률 2권(41일) 중 `highlights.longestReadBook.bookId` = `23`(먼저 INSERT된 '오래 물고 있던 책 A', id 작은 쪽). ✅ 백엔드 코드 리뷰 결론과 일치.
- **null totalPages** — `total_pages` NULL 책이 `totalPagesRead` 합산에서 0 처리 (month 1552 = 기존 932 + 300 + 320 + 0). ✅
- `recommendedCaption` 도 period별로 다르게 나옴.
- 응답 필드명: `completedBookCount`, `totalPagesRead`, `genreRatios[].{genre,count,percentage}`,
  `monthlyTrend[].{yearMonth,completedCount}`, `highlights.{topGenre,longestReadBook,fastestReadBook}`,
  `periodLabel`, `recommendedCaption`.
- ※ 정확한 수치는 **실행한 날짜에 따라 달라짐** (상대날짜라 매 실행마다 재계산).

## 5. 확인 완료 (백엔드 회신 + 테스터 실측, 2026-09-08)

| 항목 | 결과 |
|---|---|
| 분기 경계 계산 (`?date=2026-04`→Q2, `?date=2026-07`→Q3) | ✅ 백엔드 코드 리뷰 — `quarterStartMonth()` 정상 |
| 연간 `monthlyTrend` = 마지막 달 기준 직전 6개월 고정 (year→Jul~Dec) | ✅ 실측 `07~12: 2·2·6·0·0·0`. YEAR는 `periodEnd`가 항상 12/31 고정이라 안 지난 달은 0 |
| `totalPages` NULL 책 합산 | ✅ 시드에 NULL 1권 추가 → 실측: 0으로 합산 (null-safe) |
| 완독 기간 동률 tie-break (id 작은 쪽) | ✅ 시드에 동률 2권(41일) 추가 → 실측: `longestReadBook.bookId=23`(먼저 INSERT, 작은 id) |
