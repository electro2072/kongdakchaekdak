> **이 문서는 로컬 환경의 `reading-record-tester-agent`가 직접 실행하는 런북입니다.**

> 각 케이스는 "명령 → 관찰 → 판정" 세 줄로 되어 있고, 판정은 **logcat 문자열로만** 합니다.

- 대상 슬라이스: **S1 — 공용 `apiFetch` + 토큰 저장/복원** (커밋 `ae86667`)
- §5 공식 완료 조건: **로그인 → 앱 강제종료 → 재실행 → 로그인 유지됨**
- 대상 A표 행: **#5 `GET /api/auth/me`** — 통과 시 `실기기` ✖→✔, 🟡→✅, 연동률 **4/37 → 5/37**

## A. 에이전트 준수사항

1. **`frontend/`, `backend/`, `design/` 의 어떤 파일도 수정하지 않는다.** 산출물은 `docs/test/` 아래에만 쓴다.
2. 자동화 테스트 코드를 작성하지 않는다. 필요하다고 판단되면 리포트에 제안만 남기고 코드는 FE 에이전트에 넘긴다.
3. **버그를 직접 고치지 않는다.** 원인이 명백해도 리포트만 한다.
4. **실기기/에뮬레이터로 실제 확인하기 전에는 A표를 절대 ✅로 바꾸지 않는다.** (§6 갱신 규칙)
5. 결과는 `docs/test/reports/YYYY-MM-DD.md` (같은 날 두 번째면 `-b`) 로 남긴다.

### B-1. 에뮬레이터 이미지 요건 ⚠️ 먼저 확인할 것

## D. 🚨 거짓 PASS 함정 — 반드시 읽을 것

`AuthContext`는 복원 실패를 두 갈래로 나눈다.

| 상황 | 동작 |
|---|---|
| 401 (토큰 죽음) | 토큰 폐기 → 로그인 화면 |
| **네트워크 오류 (`ApiError.status === 0`)** | **토큰 유지 → 그대로 메인 진입** |

의도된 설계다("지하철에서 로그아웃시키면 안 된다"). 하지만 QA 관점에서는 치명적이다.

**에뮬레이터가 인터넷에 못 나가거나 Railway가 콜드스타트 중이면, `/api/auth/me`는 한 번도 안 불렸는데
화면상으로는 "로그인 유지됨"이 되어 S1이 PASS로 보인다.**

→ 그래서 **S1-1의 PASS 근거는 화면이 아니라 `저장된 세션 복원 완료` 로그다.**
→ S1-1에서 `세션 검증 실패(네트워크) — 세션 유지`가 찍히면 **PASS가 아니라 무효**다. B-3부터 다시.

## E. ⏰ 토큰 수명 1시간

`backend/src/main/resources/application.yml:36`

### S1-1. 【§5 공식 완료 조건】 로그인 → 강제종료 → 재실행 → 로그인 유지

```bash
adb logcat -c
adb shell am start -n com.kongdakchaekdak/.MainActivity
# → 소셜 로그인(카카오/구글/네이버 중 1개)으로 실제 계정 로그인, 하단 탭 진입 확인

adb shell am force-stop com.kongdakchaekdak     # 프로세스 강제 종료
adb logcat -c
adb shell am start -n com.kongdakchaekdak/.MainActivity
```

| | |
|---|---|
| 기대 | 로그인 화면 없이 **바로 하단 탭(메인)** 진입 |
| **PASS 조건** | logcat에 **`저장된 세션 복원 완료`** |
| FAIL | 로그인 화면이 뜸 |
| **무효** | `세션 검증 실패(네트워크) — 세션 유지` → B-3부터 재실행 |

> `am force-stop`은 프로세스를 죽인다. 최근앱 스와이프와 동등하게 취급한다.
> `adb shell pm clear`는 **쓰지 말 것** — 앱 데이터까지 지워서 S1이 무조건 FAIL로 보인다.

> ⚠️ 이전에 설치했던 이미지를 쓰는 경우 **첫 실행 때 1회 로그인 화면이 뜨는 것은 정상**이다.
> 저장소가 AsyncStorage → EncryptedStorage로, 키가 `@konggdak/accessToken`(오타) →
> `@kongdakchaekdak/accessToken`으로 바뀌어 이전 세션이 이어지지 않는다(`secureStorage.ts` 주석).
> **그 1회 로그인 이후부터** 판정한다. B-5대로 클린 설치했다면 해당 없음.

## H. A표 갱신 (S1-1 PASS일 때만)

`docs/연동매트릭스_v1.md` §2.1의 **#5 행만** 갱신한다.

```
| 5 | GET | `/api/auth/me` | 앱 부팅 시 세션 복원 | ✔ | ✔ | ✔ | ✅ |
```

- 연동률: **4/37 → 5/37**
- **#5 외의 행은 건드리지 않는다.** S2(#7·#9)는 별도 검증 대상이며 이번 세션 범위가 아니다.
- S1-1이 FAIL이거나 무효면 **#5는 🟡 그대로 둔다.**
- 매트릭스 파일 수정 권한이 없다고 판단되면 **리포트에 갱신 내용만 적고 사용자에게 승인을 요청**한다.
