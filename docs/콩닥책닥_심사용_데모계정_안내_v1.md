# 콩닥책닥 — 심사용 데모 계정 안내 v1

> **작성일: 2026-09-08 · 방식 확정: Apple 로그인(iOS) + 테스트 구글 계정(공통 백업)**
> 심사 리뷰어가 소셜 로그인 장벽 없이 앱에 진입할 수 있도록 하는 준비 문서.
> 〔기입〕 표시는 계정 생성 후 채운다.

---

## 1. 방식 요약

| 스토어 | 리뷰어 진입 방법 |
|---|---|
| App Store (iOS) | 1순위: 리뷰어 본인의 Apple 계정으로 **Sign in with Apple** 가입 (별도 계정 불필요) · 2순위: 아래 테스트 구글 계정 |
| Google Play | 테스트 구글 계정 (콘솔 "앱 액세스"란에 제출) |

- 카카오·네이버 로그인은 한국 휴대폰 인증 및 검수 이슈로 리뷰어가 사용할 수 없음 → 리뷰 노트에 명시.
- 네이버 로그인은 네이버 검수 승인 전까지 등록자 본인만 로그인 가능하므로 심사 안내에서 제외.

## 2. 테스트 구글 계정 준비 체크리스트

계정: 〔기입 — 예: kongdak.review@gmail.com〕 / 비밀번호: 〔기입〕

리뷰어가 낯선 기기·해외 IP에서 로그인하면 구글이 보안 확인을 걸어 심사가 실패할 수 있다. 아래로 예방한다.

- [ ] 콩닥책닥 전용 신규 계정 생성 (개인 계정 사용 금지)
- [ ] **2단계 인증 비활성화** 유지
- [ ] 복구 이메일을 운영자 이메일(electro2072@gmail.com)로 설정 — 잠금 시 즉시 해제용
- [ ] 제출 전, 가능한 여러 기기/에뮬레이터에서 미리 로그인해 "신뢰 기록" 쌓기
- [ ] 심사 제출 기간 동안 이 계정의 보안 알림을 매일 확인 ("새 기기 로그인 차단" 뜨면 즉시 "본인 맞음" 승인)
- [ ] 심사 기간 중 비밀번호 변경 금지
- [ ] 앱에서 이 계정으로 실제 가입 완료해두기 (닉네임: 〔기입 — 예: 콩닥리뷰어〕)

## 3. 데모 데이터 채우기

빈 서재는 앱의 매력을 못 보여준다. 테스트 계정에 아래를 미리 만들어 둔다.

- [ ] 서재: 완독 1권 + 읽는 중 1권 이상 (별점·소감·사진 포함 기록 1건 이상)
- [ ] 리캡 대시보드에 통계가 보이도록 완독 데이터 확보 — `docs/test/fixtures/dashboard-seed.sql` 시드 재활용 가능 (테스트 계정 user_id로 조정)
- [ ] 그룹 1개 생성 (그룹 공유 기능 시연용)
- [ ] 공개 공유 링크 1개 생성 (리뷰 노트에 URL 첨부 → 로그인 없이 보는 기능 확인용)

## 4. App Store Connect 입력

경로: `앱 → 심사 정보(App Review Information)`

- 로그인 필요(Sign-in required): **체크**
- 사용자 이름: 〔테스트 구글 계정〕 / 비밀번호: 〔비밀번호〕
- 메모(Notes) — 아래 영문 그대로 붙여넣기:

```
HOW TO SIGN IN

This app uses social login only (Sign in with Apple, Google, Kakao, Naver).

Option 1 (recommended): Tap "Apple로 시작하기" (Continue with Apple) and sign in
with your own Apple ID. A new account is created instantly — just enter any
nickname on the next screen.

Option 2: Tap "Google로 시작하기" (Continue with Google) and use the demo
account provided above. This account is pre-filled with sample reading records
so you can see the library, stats dashboard, and sharing features right away.

NOTES
- Kakao and Naver logins require Korean phone verification and cannot be used
  for review. Apple or Google login provides identical functionality.
- Public share link (viewable without login): 〔공유 링크 기입〕
- Account deletion: Profile tab → Settings → 회원 탈퇴 (Delete Account).
```

## 5. Google Play Console 입력

경로: `앱 콘텐츠(App content) → 앱 액세스(App access)`

- "전체 또는 일부 기능이 제한됨" 선택 → 로그인 안내 추가
- 사용자 이름/비밀번호: 〔테스트 구글 계정〕
- 기타 안내 — 아래 영문 붙여넣기:

```
Sign in with the Google demo account above: tap "Google로 시작하기"
(Continue with Google) on the first screen. The account already contains
sample reading records (library, stats, sharing). Kakao/Naver logins require
Korean phone verification and are not usable for review; Google login
provides identical functionality.
```
