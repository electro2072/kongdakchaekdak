00요약

화면(Screens) → 내비게이션 → 상태/훅(Context·Hooks) → 서비스(Services) → 백엔드 API 순서의 전형적인 레이어 구조를 따르는 React Native 단일 앱입니다. 로그인·회원가입·일정·서재·서재상세·공유·프로필· 독서 대시보드(Recap) 8개 화면이 구현되어 있고, 책 검색 화면은 만들어져 있지만 내비게이터에 연결되지 않은 고아 상태입니다. 소셜 로그인(카카오/네이버/구글) SDK 연동과 isNewUser 분기는 완료되었고, 프로필·대시보드는 mock 데이터로 UI까지 완성되어 실제 API 연동만 남아 있습니다.

04상태 관리

AuthContext / useAuth()

accessToken, setAccessToken(), login(), logout() 제공. 세션 영속화가 없어 앱을 완전히 종료했다 다시 열면 로그아웃 상태로 초기화됩니다 — 테스터 시나리오 FE-SL-04~06이 이 특성을 이용해 재로그인 케이스를 재현합니다.

useTheme()

ThemeColors 인터페이스(34개 키) 기준 라이트/다크 팔레트 전환. 2026-08-27에 v1.2("잔디" 그린) → v2("책거리×송편" 그린) 리브랜딩 전체 동기화 완료.

useDashboard()

기간(month/quarter/year) 상태 + mock fetch(400ms 지연으로 로딩 스켈레톤 재현) + error/retry 관리. 실제 API 연동 시 내부 fetch 함수만 교체하면 되는 구조로 설계됨.

5.2 도서 검색 — BookSearchProvider

알라딘 Open API와 카카오 도서 검색 API를 공통 인터페이스(BookSearchProvider, search(query) 형태로 추정)로 추상화하고 AladinApi/KakaoBookApi 두 구현체를 두는 구조입니다. TODO의 "두 도서 API 결과 병합·중복 제거 로직 검증" 항목이 이 레이어와 연결됩니다.

06데이터 타입 (DTO)

// 인증
interface TokenResponse {
  accessToken: string;
  tokenType: 'Bearer';
  expiresIn: number;
  isNewUser: boolean; // true=신규가입, false=기존 로그인
}

// 대시보드
type DashboardPeriod = 'month' | 'quarter' | 'year';
type DashboardPeriodResponse = 'MONTH' | 'QUARTER' | 'YEAR';

interface GenreRatioDto { genre: string; count: number; ratio: number; }
interface MonthlyTrendDto { yearMonth: string; completedCount: number; }
interface BookHighlightDto { id: number; title: string; days: number; }
interface DashboardHighlights {
  topGenre: string | null;
  longestReadBook: BookHighlightDto | null;
  fastestReadBook: BookHighlightDto | null;
}
interface DashboardResponse {
  userId: number;
  period: DashboardPeriodResponse;
  periodLabel: string;
  startDate: string;
  endDate: string;
  completedBookCount: number;
  totalPagesRead: number;
  genreRatios: GenreRatioDto[];
  monthlyTrend: MonthlyTrendDto[];
  highlights: DashboardHighlights;
  recommendedCaption: string;
}
