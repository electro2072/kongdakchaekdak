· 로그인 화면 소셜 버튼 순서를 기획서 기준(네이버/카카오/구글)으로 수정 — v1에서 네이버 누락 오류 수정
· 마이페이지 대시보드(Recap)는 v1 내용 유지, "프로필" 탭 하위 화면으로 재배치
