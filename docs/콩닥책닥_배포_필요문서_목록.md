## 1. 필수 — 없으면 출시 불가 / 심사 리젝

### 1.1 문서 · 법무

| 항목 | 비고 | 현황 |
|---|---|---|
| 개인정보처리방침 (공개 URL) | 양 스토어 + 소셜 로그인 콘솔 전부 요구. 국내 개인정보보호법상으로도 필수 | ⚠️ 법정 필수 항목(보호책임자·파기절차·권익침해 구제·위탁·국외이전) 보강 완료 (`0eaa12f`). 남은 것: 공개 URL 호스팅(GitHub Pages 권장) + 각 스토어·콘솔에 URL 등록 |
| 이용약관 | 회원 가입·UGC(독서 기록/사진) 게시·신고 정책의 근거. Apple은 UGC 앱에 사실상 요구 | ✅ `TERMS.md` 커밋 완료 (`e0d08fe`). 시행일·부칙 날짜만 출시일에 맞춰 기입 필요 |
| 만 14세 미만 가입 정책 | 받을지 여부 + 받으면 법정대리인 동의 절차. 소셜 로그인은 나이 미수집이라 약관 체크 등 처리 방법 결정 필요 | ✅ "가입 불가"로 확정 — 약관 제5조4항 + `PRIVACY.md` §9 |
| 스토어 등록 메타데이터 | 앱 이름·설명·아이콘·기기별 스크린샷·카테고리·연령등급·지원(Support) URL | ⚠️ 텍스트·스크린샷 제작 완료 (`콩닥책닥_스토어등록텍스트_v2.md`, 스크린샷 6종×2). 앱 이름·카테고리·지원 URL 확정. 남은 것: 콘솔 입력 + 연령등급(IARC) 설문 |

### 1.2 iOS (App Store)

| 항목 | 비고 | 현황 |
|---|---|---|
| Apple Developer Program | $99/년 | ❌ |
| App Privacy 신고 | App Store Connect에 수집 데이터 유형 입력. `PRIVACY.md` 내용과 일치해야 함 | ❌ 콘솔 입력 미완 (준비: `콩닥책닥_데이터수집신고_매핑표_v1.md`에 6항목 정리됨) |
| Privacy Manifest (`PrivacyInfo.xcprivacy`) | 2024~ 필수. Required Reason API + 서드파티 SDK 신고 | ✅ 수집 데이터 6종 + 사용 목적 작성 완료 (`ddb671a`). 서드파티 SDK(카카오·네이버·구글) Required Reason 신고분만 최종 확인 필요 |
| Info.plist 권한 사유 문자열 | 책 사진 업로드 → `NSCameraUsageDescription`, `NSPhotoLibraryUsageDescription`. 촬영 위치 → `NSLocationWhenInUseUsageDescription` | ✅ 카메라·사진·위치 3종 실제 문구 작성 완료 (`ddb671a`) |
| Sign in with Apple | 구글·카카오·네이버를 제공하면 Apple 로그인도 의무 (App Review Guideline 4.8) | ❌ 미구현 (요구사항정의서 R-04) |
| 심사용 데모 계정 | 소셜 로그인만 있으면 리뷰어 진입 불가 → 테스트 계정 / 우회 로그인 제공 | ⚠️ 안내 문서 작성됨 (`콩닥책닥_심사용_데모계정_안내_v1.md`). 실제 계정 생성·시딩 미완 (N-03) |
| Export Compliance 답변 | HTTPS만 쓰면 "면제"로 답변, 답변 자체는 필수 | — |

### 1.4 소셜 로그인 (제공하는 것만 필수)

| 항목 | 현황 |
|---|---|
| 각 콘솔 앱 등록 + 번들ID / 패키지명 / redirect URI | ⚠️ 카카오·구글·네이버 Android E2E 3사 PASS (`47f2fa4`). 남은 것: 카카오 콘솔 앱명 "콩닥책닥" 리네임 + iOS 번들ID 등록 (`소셜로그인_설정현황.md`) |
| 구글: SHA-1 지문(debug+release) / 카카오: 키 해시 | ⚠️ debug 완료(E2E PASS). release 지문·키 해시는 N-02 Android 서명 준비에서 |
| 네이버 로그인 검수 | ❌ (검수 전엔 등록자 본인만 로그인 가능 — N-04) |
| 카카오 비즈앱 전환 | 이메일 등 추가 정보 수집 시에만 |
| 개인정보처리방침 URL을 각 콘솔에도 제출 | ❌ (공개 URL 호스팅 선행 필요) |

### 1.5 UGC · 계정 (Apple / Google 공통 심사 필수)

> 8/31 최초 작성 시 누락. UGC(독서 기록·사진을 그룹/공유로 타인에게 노출) 앱은 아래가 없으면 iOS 리젝.

| 항목 | 비고 | 현황 |
|---|---|---|
| 회원 탈퇴 (앱 내 계정 삭제) | Apple Guideline 5.1.1(v) · Google Play 계정 삭제 정책. 약관 제11조·개인정보처리방침·계정 삭제 안내가 이미 이 기능을 전제 | ❌ 미구현 (요구사항정의서 R-01) |
| 게시물 신고 | Apple Guideline 1.2 — UGC 앱 필수. 약관 제10조가 "신고 접수 후 24시간 내 조치" 공지 | ❌ 미구현 (R-02) |
| 사용자 차단 | Apple Guideline 1.2 — 불쾌한 사용자 차단 수단 필수. 약관 제10조 3항이 공지 | ❌ 미구현 (R-03) |
| 계정 삭제 안내 페이지 (공개 URL) | Google Play가 계정·데이터 삭제 경로 URL 제출 요구 | ⚠️ 안내 문서 작성됨 (`ACCOUNT_DELETION.md`). 공개 URL 호스팅 + 앱 탈퇴 기능 연동 미완 |

## 2. 필수 아님 — 권장 / 조건부

### 2.1 팀 문서 (심사와 무관, 있으면 유지보수에 유리)

| 문서 | 현황 |
|---|---|
| API 명세서 (별도 문서) | ⚠️ 백엔드 Swagger(springdoc)로 갈음 가능 |
| 아키텍처 / 배포 구조도 | ⚠️ 프론트·백엔드 아키텍처 문서 v1 있음 (`docs/[frontend]·[backend] 독서기록앱_아키텍처문서_v1`). 배포 구조도는 미작성 |
| ERD (관계도) | ✅ 테이블정의서로 갈음 |
| 코딩 컨벤션 / 브랜치 전략 | ❌ (레포는 main 직커밋) |
| QA 테스트 계획 · 시나리오 | ✅ `docs/test/` |
| 릴리스 체크리스트 · 릴리스 노트 | ⚠️ 출시 과제는 `콩닥책닥_출시준비_요구사항정의서_v1.md`가 부분 갈음. 릴리스 노트는 미작성 |
| 운영 런북 (장애 대응·롤백) | ❌ |
| 제품 기획서 | ⚠️ 뼈대 `콩닥책닥_기획서_v1.md` (작성 중) |

### 2.2 조건부 (해당 기능 사용 시 필수)

| 항목 | 조건 |
|---|---|
| 오픈소스 라이선스 고지 화면 | RN 의존성 라이선스 조건상 필요할 수 있음 (권장) |
| iOS `LSApplicationQueriesSchemes` | 카카오 / 네이버 SDK가 카카오톡·네이버앱 전환 기능 사용 시 — ✅ Info.plist에 카카오·네이버 스킴 5종 등록 완료 |
| Android App Links + `assetlinks.json` | 공유 링크(`kongdakchaekdak.app/share/...`)를 앱으로 열 때 |
| ATT + `NSUserTrackingUsageDescription` | 광고 추적 시 |
| 위치기반서비스 이용약관 | 사진 촬영 장소 남기기 기능(요구사항정의서 R-05) 확정으로 해당됨. Info.plist 위치 권한 문구는 작성 완료 — 위치기반서비스 이용약관 별도 고지 필요 여부 검토 |
| 통신판매업 신고 / 결제 약관 | 인앱 결제·커머스 도입 시 (현재 해당 없음) |

### 2.3 선택 (안 해도 무방)

- 마케팅 URL, 프로모션 텍스트
- TestFlight / Play 비공개 테스트 트랙 (권장이나 프로덕션 직접 제출도 가능)
- 스토어 A/B 테스트, 사전 등록
