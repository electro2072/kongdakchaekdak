# 콩닥책닥 — 앱 배포 시 필요 문서 목록

**작성일: 2026-08-31**

App Store / Google Play 심사 통과를 기준으로 "없으면 출시 불가"와 "권장 / 조건부"를 구분한다.
현황 표기: ✅ 있음 · ⚠️ 부분 / 보강 필요 · ❌ 없음

---

## 1. 필수 — 없으면 출시 불가 / 심사 리젝

### 1.1 문서 · 법무

| 항목 | 비고 | 현황 |
|---|---|---|
| 개인정보처리방침 (공개 URL) | 양 스토어 + 소셜 로그인 콘솔 전부 요구. 국내 개인정보보호법상으로도 필수 | ⚠️ 초안 `PRIVACY.md` 있음. 개인정보 보호책임자·파기 절차·권익침해 구제방법·국외 이전 항목 보강 + 공개 URL 호스팅(GitHub Pages 권장) 필요 |
| 이용약관 | 회원 가입·UGC(독서 기록/사진) 게시·신고 정책의 근거. Apple은 UGC 앱에 사실상 요구 | ❌ |
| 만 14세 미만 가입 정책 | 받을지 여부 + 받으면 법정대리인 동의 절차. 소셜 로그인은 나이 미수집이라 약관 체크 등 처리 방법 결정 필요 | ❌ 결정 필요 |
| 스토어 등록 메타데이터 | 앱 이름·설명·아이콘·기기별 스크린샷·카테고리·연령등급·지원(Support) URL | ❌ |

### 1.2 iOS (App Store)

| 항목 | 비고 | 현황 |
|---|---|---|
| Apple Developer Program | $99/년 | ❌ |
| App Privacy 신고 | App Store Connect에 수집 데이터 유형 입력. `PRIVACY.md` 내용과 일치해야 함 | ❌ |
| Privacy Manifest (`PrivacyInfo.xcprivacy`) | 2024~ 필수. Required Reason API + 서드파티 SDK 신고 | ⚠️ 파일만 존재, 내용 미작성 |
| Info.plist 권한 사유 문자열 | 책 사진 업로드 → `NSCameraUsageDescription`, `NSPhotoLibraryUsageDescription`. 촬영 위치 → `NSLocationWhenInUseUsageDescription`(현재 빈 문자열) | ❌ |
| Sign in with Apple | 구글·카카오·네이버를 제공하면 Apple 로그인도 의무 (App Review Guideline 4.8) | ❌ |
| 심사용 데모 계정 | 소셜 로그인만 있으면 리뷰어 진입 불가 → 테스트 계정 / 우회 로그인 제공 | ❌ |
| Export Compliance 답변 | HTTPS만 쓰면 "면제"로 답변, 답변 자체는 필수 | — |

### 1.3 Android (Google Play)

| 항목 | 비고 | 현황 |
|---|---|---|
| Google Play Developer 계정 | $25 (1회) | ❌ |
| Data safety 양식 | 수집·공유 데이터 신고. `PRIVACY.md` 내용과 일치해야 함 | ❌ |
| 콘텐츠 등급 설문 (IARC) | | ❌ |
| 타겟 API 레벨 충족 | 매년 상향, 미달 시 등록 불가 | ⚠️ 빌드 시 확인 |
| Play App Signing / 키스토어 | 업로드 키 생성·백업 | ❌ |
| 특수 권한 선언 양식 | 정확한 알람·전체화면 인텐트·백그라운드 위치 등 사용 시 (조건부) | 사용 권한 확인 필요 |

### 1.4 소셜 로그인 (제공하는 것만 필수)

| 항목 | 현황 |
|---|---|
| 각 콘솔 앱 등록 + 번들ID / 패키지명 / redirect URI | ⚠️ 진행 중 (`소셜로그인_설정현황.md`) |
| 구글: SHA-1 지문(debug+release) / 카카오: 키 해시 | ⚠️ |
| 네이버 로그인 검수 | ❌ (검수 전엔 등록자 본인만 로그인 가능) |
| 카카오 비즈앱 전환 | 이메일 등 추가 정보 수집 시에만 |
| 개인정보처리방침 URL을 각 콘솔에도 제출 | ❌ |

## 2. 필수 아님 — 권장 / 조건부

### 2.1 팀 문서 (심사와 무관, 있으면 유지보수에 유리)

| 문서 | 현황 |
|---|---|
| API 명세서 (별도 문서) | ⚠️ 백엔드 Swagger(springdoc)로 갈음 가능 |
| 아키텍처 / 배포 구조도 | ❌ |
| ERD (관계도) | ✅ 테이블정의서로 갈음 |
| 코딩 컨벤션 / 브랜치 전략 | ❌ (레포는 main 직커밋) |
| QA 테스트 계획 · 시나리오 | ✅ `docs/test/` |
| 릴리스 체크리스트 · 릴리스 노트 | ❌ |
| 운영 런북 (장애 대응·롤백) | ❌ |
| 제품 기획서 | ⚠️ 뼈대 `콩닥책닥_기획서_v1.md` (작성 중) |

### 2.2 조건부 (해당 기능 사용 시 필수)

| 항목 | 조건 |
|---|---|
| 오픈소스 라이선스 고지 화면 | RN 의존성 라이선스 조건상 필요할 수 있음 (권장) |
| iOS `LSApplicationQueriesSchemes` | 카카오 / 네이버 SDK가 카카오톡·네이버앱 전환 기능 사용 시 |
| Android App Links + `assetlinks.json` | 공유 링크(`kongdakchaekdak.app/share/...`)를 앱으로 열 때 |
| ATT + `NSUserTrackingUsageDescription` | 광고 추적 시 |
| 위치기반서비스 이용약관 | 위치 정보 사용 시 (현재 Info.plist 빈 위치 권한은 제거 권장) |
| 통신판매업 신고 / 결제 약관 | 인앱 결제·커머스 도입 시 (현재 해당 없음) |

### 2.3 선택 (안 해도 무방)

- 마케팅 URL, 프로모션 텍스트
- TestFlight / Play 비공개 테스트 트랙 (권장이나 프로덕션 직접 제출도 가능)
- 스토어 A/B 테스트, 사전 등록

## 3. 지금 우선순위 (배포 전 블로킹)

1. 이용약관 작성
2. 개인정보처리방침 — 법정 필수 항목 보강 + 공개 URL 호스팅
3. Sign in with Apple 구현
4. Info.plist 권한 사유 문자열 (카메라 / 사진 / 위치)
5. 심사용 데모 계정 마련
6. Apple / Google 개발자 계정 등록
7. 네이버 로그인 검수 신청
