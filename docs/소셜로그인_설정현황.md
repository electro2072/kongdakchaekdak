> 최종 업데이트: 2026-08-29

> `.env`는 git에 안 올라가서, 이 문서로 진행 상황을 레포에 남긴다.

## 구조 요약

모바일 앱이 각 제공자 **네이티브 SDK로 직접 로그인**해서 받은 토큰(카카오·네이버 access token,
구글 ID token)을 백엔드로 넘기고, 백엔드는 그 토큰으로 제공자 userinfo만 조회한다
(`SocialAuthService`, `KakaoOAuthClient` / `GoogleOAuthClient` / `NaverOAuthClient`).

- **서버 콜백(redirect) URL을 쓰지 않는다.** → 제공자 콘솔에 "웹"이 아니라 **iOS/Android 네이티브 플랫폼**으로 등록.
- 백엔드가 실제로 필요로 하는 값: 구글 `GOOGLE_CLIENT_ID`(웹 클라이언트 ID, aud 검증용) 하나뿐.
  카카오·네이버는 `/v2/user/me`·`/v1/nid/me`에 토큰만 보내서 client id/secret 미사용.
- 나머지 키(카카오 네이티브 앱 키, 구글 iOS 클라이언트 ID, 네이버 secret 등)는 **프론트 네이티브 설정용**.

### E2E에서 발견된 이슈 (테스터 에이전트가 리포트/추적할 것)

1. **[콘솔] 카카오 앱 이름이 "독서 기록 어플 개발"** — 카카오 로그인 동의화면에 그대로 노출됨. Kakao Developers > 앱 설정 > 일반 > 앱 기본 정보 > 앱 이름을 **"콩닥책닥"**으로 변경 필요. (앱 ID `1502106`)
2. **[프론트] 신규 가입 유저인데 일정/서재 탭에 mock 데이터 표시** — "아몬드 62%", "3권 완독", 독서모임 "책벙개", "읽고 있는 책 2" 등이 데이터 없는 신규 계정에도 보임. 로그인·온보딩만 백엔드 연동돼 있고 나머지 탭은 mock 또는 empty-state 미구현. 프론트 에이전트 대상.
3. **[빌드] 16KB page size 미대응 경고** — 앱 실행 시 "This app isn't 16 KB compatible" 다이얼로그. RN 0.74 + 일부 네이티브 라이브러리가 4KB 정렬. 현재 기기/에뮬 대부분에선 무해하나 **Google Play 제출 차단 요인**. RN 버전업(0.75+) + NDK r27 + 의존성 업으로 해결. 스토어 제출 준비 단계에서 처리.
4. **[개발환경] "Cannot connect to Metro" 토스트** — 디버그 빌드가 HMR용으로 계속 재연결 시도. 앱 기능엔 무해. 에뮬 재부팅마다 `adb reverse tcp:8081 tcp:8081` 필요.
5. **[개발환경, E2E 시 주의]** API 37(프리뷰) "16k" 에뮬 이미지는 Play가 Chrome을 반쯤 업데이트하다 꼬여 커스텀탭이 하얗게/까맣게만 뜸(`cr_ChildProcessConn: classpath doesn't match`). **API 34/35 정식 + Google Play 이미지**로 테스트할 것. (`pm clear com.android.chrome`로도 완전히 안 고쳐짐 — 이미지 교체가 답)

### 미검증

- **iOS E2E** — 맥 필요. 미착수. iOS 네이티브 설정(카카오 스킴, 구글 역순 클라이언트 ID URL 스킴, 네이버 `NAVER_URL_SCHEME_IOS=com.kongdakchaekdak`)은 코드엔 반영돼 있으나 실기 검증 안 됨.
