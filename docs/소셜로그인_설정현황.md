# 소셜 로그인 설정 현황 (카카오 / 구글 / 네이버)

> 최종 업데이트: 2026-08-29
> 작성 배경: 3사 개발자 콘솔 등록 + 백엔드 `.env` 반영 작업을 진행함. 콘솔 작업은 레포 밖이고
> `.env`는 git에 안 올라가서, 이 문서로 진행 상황을 레포에 남긴다.

## 구조 요약

모바일 앱이 각 제공자 **네이티브 SDK로 직접 로그인**해서 받은 토큰(카카오·네이버 access token,
구글 ID token)을 백엔드로 넘기고, 백엔드는 그 토큰으로 제공자 userinfo만 조회한다
(`SocialAuthService`, `KakaoOAuthClient` / `GoogleOAuthClient` / `NaverOAuthClient`).

- **서버 콜백(redirect) URL을 쓰지 않는다.** → 제공자 콘솔에 "웹"이 아니라 **iOS/Android 네이티브 플랫폼**으로 등록.
- 백엔드가 실제로 필요로 하는 값: 구글 `GOOGLE_CLIENT_ID`(웹 클라이언트 ID, aud 검증용) 하나뿐.
  카카오·네이버는 `/v2/user/me`·`/v1/nid/me`에 토큰만 보내서 client id/secret 미사용.
- 나머지 키(카카오 네이티브 앱 키, 구글 iOS 클라이언트 ID, 네이버 secret 등)는 **프론트 네이티브 설정용**.

- 완료 항목:
  - 네이티브 앱 키에 Android(패키지 `com.kongdakchaekdak` + 키해시) / iOS(번들 `com.kongdakchaekdak`) 등록
  - 카카오 로그인 활성화 ON, OpenID Connect OFF
  - 동의항목: 닉네임(profile_nickname) = **선택 동의** (거부해도 로그인 가능, 백엔드가 랜덤 닉네임으로 대체)
- 키:
  - REST API 키 → 백엔드 `.env`의 `KAKAO_CLIENT_ID`
  - **네이티브 앱 키** → 프론트 `strings.xml` / `Info.plist` (REST API 키와 다른 값). 커스텀 스킴 `kakao{네이티브앱키}`
  - 클라이언트 시크릿: 콘솔엔 있으나 백엔드 미사용
- 검증: `POST /api/auth/kakao` (실제 토큰) → 200 + JWT, `/me` 유저 생성, 같은 토큰 재요청 시 기존 유저(find-or-create) 확인
- 개인 앱이라 이메일은 필수 동의로 못 받음 → 필요해지면 비즈 앱 전환(키/코드 불변)

## 네이버 — 콘솔 설정 완료(사용자 직접), 해피패스는 프론트 연동 시

- 앱 "콩닥책닥", 환경 = Android/iOS, 제공 정보 = 별명(nickname)
- Client ID / Secret → 백엔드 `.env`의 `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET`

- 네이버 앱은 기본 "개발중" 상태 — 앱 소유자/등록 멤버만 로그인 가능. 정식 출시 시 검수 필요
- iOS URL Scheme: 사용자가 콘솔에 등록한 값과 앱 코드가 일치해야 함

- 라이브러리 설치: `@react-native-seoul/kakao-login`, `@react-native-google-signin/google-signin`, `@react-native-seoul/naver-login`
- 네이티브 설정 반영 위치:
  - 카카오: `strings.xml`, `AndroidManifest.xml`, `Info.plist` (네이티브 앱 키 + 스킴)

- 프론트 필요 키 3종은 팀 공유 채널 / 백엔드 `.env` 참고:
  `KAKAO_NATIVE_APP_KEY`, `GOOGLE_IOS_CLIENT_ID`, `NAVER_URL_SCHEME_IOS`(사용자 지정값)
