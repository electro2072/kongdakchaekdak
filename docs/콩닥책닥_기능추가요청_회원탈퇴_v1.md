## 1. 왜 필요한가

1. **Apple 심사 필수** — 계정 생성이 가능한 앱은 앱 안에서 계정 삭제도 시작할 수 있어야 합니다 (App Review Guideline 5.1.1(v)). 소셜 로그인으로 가입을 받는 콩닥책닥은 해당 대상이며, 탈퇴 기능이 없으면 리젝됩니다.
2. **문서와 실제 동작의 일치** — 이미 배포용 문서 3종(개인정보처리방침·이용약관·계정삭제안내)이 "앱 내 설정에서 탈퇴 가능, 탈퇴 즉시 파기"를 전제로 작성되어 있습니다. 문서에 있는데 앱에 없으면 심사·법적 리스크 모두 발생합니다.
3. Google Play 쪽은 웹 안내 페이지(`ACCOUNT_DELETION.md`)로 URL 요건을 충족하지만, 그 페이지의 1순위 안내가 "앱에서 직접 삭제하기"이므로 기능이 실제로 존재해야 합니다.

## 2. 요구사항 요약

- 진입 경로: **프로필 탭 → 설정 → 회원 탈퇴**
- 탈퇴 전 확인 단계 1회 (삭제되는 내용 고지 + 위험 액션 확인)
- 탈퇴 즉시 처리 — 유예 기간·대기 기간 없음 (ACCOUNT_DELETION.md에 그렇게 공지됨)
- 탈퇴 완료 후 로그인(온보딩) 화면으로 이동

## 4. 삭제 스펙 (ACCOUNT_DELETION.md 기준 — 이 목록이 곧 공지된 약속)

**즉시 삭제**
- 계정: 소셜 로그인 식별자, 닉네임, 프로필 이미지, 한 줄 소개, 성별, 관심 분야
- 독서 기록: 서재 책 목록, 별점, 소감, 읽은 기간, 업로드 사진, 촬영 장소 좌표
- 공유: 공유 카드, 공유 이력, 공개 공유 링크(접근 불가 처리)
- 그룹: 멤버십 (활동 흔적은 3장 기획 결정에 따름)

**법정 보관 후 파기**
- 접속 로그(로그인 기록): 통신비밀보호법, 3개월

## 5. 수용 기준 (완료 판정)

1. 프로필 → 설정 → 회원 탈퇴 → 확인 다이얼로그 → 탈퇴 완료 → 온보딩 화면 플로우가 동작한다
2. 탈퇴 후 같은 소셜 계정으로 재로그인하면 **신규 가입 플로우**(닉네임 입력)로 진입한다
3. 탈퇴 전 생성한 공개 공유 링크에 접근하면 콘텐츠가 보이지 않는다
4. 탈퇴 전 발급된 JWT로 API를 호출하면 인증 실패한다
5. DB에서 해당 사용자의 4장 "즉시 삭제" 데이터가 조회되지 않는다
