🌱 콩닥책닥 — 스플래시 화면 (확정) v1

앱 실행 직후 잠깐 보이는 시작 화면. 쑥송편 그린 배경을 화면 전체에 채우고 "콩닥/책닥" 워드마크만 크림색으로 크게 배치하는 풀블리드 워드마크형으로 확정했습니다.

Ver 1 (확정) 작성일 2026-08-27 Splash Screen — Final
결정 경위 — 스플래시 화면은 이전까지 계속 보류 상태였는데(앱 아이콘이 정해지지 않아서), 앱 아이콘이 v3 텍스트 워드마크형으로 확정된 뒤 진행했습니다. "① 심플 아이콘 중앙형"(크림 배경 + 작은 아이콘)과 "② 풀블리드 워드마크형"(그린 배경 전체 + 큰 워드마크) 두 방향을 시안으로 비교했고(splash_screen_concept.html), 사용자가 ②번을 선택해 확정했습니다.
왜 다크모드 짝이 없나요 — 스플래시는 OS가 앱 로딩 전에 가장 먼저 띄우는 화면이라 실제 iOS/Android 런치스크린 관례상 시스템 다크모드와 무관하게 보통 단일 버전으로 만듭니다. 이 문서도 라이트/다크 구분 없이 하나로 확정했습니다.
색상 재사용 — 배경·텍스트 색 모두 앱 아이콘 v3와 동일한 값을 그대로 사용해, 아이콘 → 스플래시 → 앱 진입 화면까지 색이 끊기지 않고 이어지도록 했습니다.
