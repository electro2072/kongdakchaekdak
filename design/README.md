# design/ — 디자인 시스템 & Hi-Fi 목업

이 폴더는 앱의 비주얼 디자인 산출물(컬러 팔레트, 타이포그래피/아이콘, Hi-Fi 목업)의 실제 소스 파일을 담습니다. 각 산출물의 결정 사항 요약은 claude.ai 프로젝트 문서함에도 마크다운으로 정리되어 있습니다:

- `독서기록앱_디자인시스템_컬러팔레트_v1.md`
- `독서기록앱_디자인시스템_타이포_아이콘_v1.md`
- `독서기록앱_디자인시스템_Hifi목업_v1.md`

## 파일 구성

| 파일 | 설명 |
|---|---|
| `color_chips.html` | 연두 테마 컬러 팔레트 v1 — 라이트/다크 스와치, 대비 검증 결과, 버튼/배지/카드 적용 예시 |
| `typography_and_icons.html` | Pretendard 타입 스케일 + Lucide 아이콘 24종 가이드 |
| `hifi_mockup_v1.html` | `../docs/독서기록공유앱_화면설계서_wireframe_v2-5.html`의 11개 프레임에 디자인 시스템을 입힌 Hi-Fi 목업 |
| `gen_palette.js`, `gen_dark*.mjs`, `gen_status.mjs`, `check_contrast.mjs`, `check_status.mjs`, `search_warning.mjs` | 컬러 값을 도출/검증하는 데 쓴 스크립트 (참고/재현용 기록) |

## 스크립트 실행에 대한 주의

`gen_*`/`check_*` 스크립트는 다음 두 외부 경로에 의존합니다 (이 저장소 밖에 있음):

- `culori` npm 패키지 — 로컬에서 재현하려면 `npm install culori` 필요
- dataviz 스킬의 `validate_palette.js` (Anthropic 번들 스킬 경로) — 이 검증기가 없으면 색맹 안전성/대비 체크 로직을 다시 구현해야 함

즉 이 스크립트들은 **"이 색이 어떻게 도출됐는지"를 기록해두기 위한 자료**이고, 그대로 재실행 가능한 빌드 스크립트는 아닙니다.

## 버전 관리 방식

- 각 산출물은 파일명에 `v1`, `v2` 형태로 버전을 표기합니다.
- 이 폴더가 git으로 커밋되기 시작한 시점(2026-07-21)부터는, 새 버전을 만들 때 기존 파일을 덮어쓰지 않고 새 파일(`_v2.html` 등)을 추가하거나, 같은 파일 안에 변경 이력(changelog) 섹션을 남기는 두 방식을 상황에 따라 씁니다 — 와이어프레임 문서가 후자 방식(문서 내 changelog)의 예시입니다.
- git 커밋 이력 자체가 세부 변경 diff를 보존하므로, 파일명 버전 표기는 "현재 어떤 버전을 보고 있는지"를 사람이 알아보기 위한 용도이고, 실제 변경 이력 추적은 git log가 담당합니다.
