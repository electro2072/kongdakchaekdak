🔔 콩닥책닥 — 알림(푸시) 아이콘 v1

Android 상태 표시줄 알림 전용 실루엣 아이콘. 앱 아이콘(텍스트 워드마크형)과는 별개의 신규 산출물입니다.

Ver 1 (신규) 최초 작성 2026-09-07 최종 수정 2026-09-07 Notification Icon — Android 전용
왜 필요한가 — 사용자가 "앱 알림용 아이콘은 따로 없어도 되나요?"라고 질문. 확인해보니 design/에 앱 아이콘·스플래시만 있고 알림 전용 아이콘은 없었습니다. iOS는 알림에 앱 아이콘을 그대로 재사용해서 별도 에셋이 필요 없지만, Android는 상태 표시줄 알림 아이콘을 OS가 강제로 흰색 실루엣 + 완전 투명 배경으로 렌더링합니다(원본에 색이나 그라데이션을 넣어도 무시되고 단색 실루엣으로 표시됨) — 그래서 배경이 있는 지금의 앱 아이콘을 그대로 쓸 수 없습니다.
왜 앱 아이콘을 축소해서 쓰지 않는가 — 확정된 앱 아이콘(app_icon.html v2.1)은 "콩닥 / 책닥" 두 줄 텍스트 워드마크라, 24px 안팎의 아주 작은 실루엣으로 축소하면 글자가 뭉개져 알아보기 어렵습니다. 그래서 앱 아이콘과는 완전히 별개의 신규 심볼이 필요합니다.
심볼 선택 — 사용자가 "'콩' 하나로, 그냥 글자로" 만들어달라고 요청 — 앱 이름("콩닥책닥")의 첫 글자 한 글자만 굵게 사용하는 단순한 방식으로 결정했습니다. 두 줄 워드마크보다 훨씬 단순해서 작은 실루엣에서도 알아보기 쉽습니다.
안전 여백 — Android 상태 표시줄 아이콘은 캔버스 가장자리까지 꽉 채우면 다른 아이콘들과 나란히 놓였을 때 잘리거나 붙어 보이기 쉬워, 글리프를 캔버스의 약 70% 크기로 중앙 배치하고 나머지를 여백으로 남겼습니다(앱 아이콘의 Android adaptive 전경 레이어에 적용한 "안전영역" 원칙과 같은 사고방식).

실제 내보내기 요소 (Android 5개 밀도, 24dp 기준)

아래 5개 블록은 Android 표준 밀도별 실제 픽셀 크기(24dp 기준 × 배율)로 렌더링되어 있고, Playwright로 이 요소들을 투명 배경 그대로 스크린샷해서 PNG로 추출합니다 — 별도 이미지 생성 없이 벡터 기반으로 정확한 크기를 뽑았습니다. 실제 React Native/Android 프로젝트에는 밀도별 drawable-mdpi/-hdpi/-xhdpi/-xxhdpi/-xxxhdpi 폴더에 같은 파일명(예: ic_stat_notify.png)으로 각각 넣으면 됩니다.

① mdpi — 24×24px (1x, 기준 밀도)
② hdpi — 36×36px (1.5x)
③ xhdpi — 48×48px (2x)
④ xxhdpi — 72×72px (3x)
⑤ xxxhdpi — 96×96px (4x)

iOS는 왜 없는가

iOS는 알림 배너·잠금화면·알림 센터 어디에서도 앱 아이콘을 자동으로 그대로 사용합니다(별도 규격이 없음). 리치 푸시 알림(이미지 첨부 등)을 위한 Notification Service Extension을 나중에 도입하게 되면 그때 별도로 다룰 수 있지만, 현재 범위에서는 iOS용 알림 아이콘 에셋이 필요 없습니다.
