Ver 1.19 375 × 812 (iPhone 기준) High-fidelity Mockup 최초 작성 2026-07-21 최종 수정 2026-09-09
이 문서와 와이어프레임의 관계 — 화면 구조·문구·플로우는 화면설계서_wireframe_v2-5.html과 동일합니다 (프레임 번호도 그대로 대응). 이 문서는 그 구조 위에 실제 컬러 팔레트·Pretendard·Lucide 아이콘만 입힌 것으로, 기능 스펙에 대한 상세 설명(각 요소 번호별 주석)은 원본 와이어프레임을 참고해주세요. 여기서는 시각적으로 어떻게 보이는지에만 집중합니다.
변경 이력 안내 (v1.17, 2026-09-08) — v1.1~v1.16의 상세 변경 이력을 hifi_mockup_changelog.md(같은 폴더)로 분리했습니다. 파일 용량이 계속 늘어나는 것을 줄이기 위한 조치이고, 화면 구조·CSS·아이콘 등 실제 내용에는 영향이 없습니다. 최신 버전 변경 사항만 아래에 남깁니다.
v1.17 변경 이력 (2026-09-08) — "지금까지 쓴 문구들이 딱딱하다"는 피드백을 받아, 사용자가 준비한 UX 보이스 확장 문서("밥상" 레이어)를 기준으로 이 문서 안에 실제로 존재하는 문구 중 규칙상 "맛을 내도 되는" 자리만 골라 교체했습니다(완독 버튼 라벨 간결화, 리캡 하이라이트, 최근 활동 리스트, 서재 최초 빈 상태, 알림 목록 각 1곳) — 실패·경고·고빈도 문구는 원칙대로 손대지 않았습니다. 자세한 전/후 목록은 hifi_mockup_changelog.md와 프론트 요청 문서(독서기록앱_프론트요청_UX문구_밥상보이스적용_v1.md) 참고. 라이트·다크 각각 Playwright로 재검증, <div> 태그 균형 변경 없음(문구 교체만, 신규 요소 없음).
v1.18 변경 이력 (2026-09-08) — 사용자 결정 2건 반영: ① 비회원으로 둘러보기 기능 폐기 — Frame 01 하단의 "비회원으로 둘러보기" 링크를 제거했습니다. ② iOS 전용 Apple 로그인 버튼 신규 추가 — App Store 심사 가이드라인(4.8)상 다른 제3자 소셜 로그인을 제공하면 Apple 로그인도 동등하거나 더 눈에 띄게 제공해야 해서, 버튼 스택 맨 위에 배치했습니다. 신규 .btn-apple 클래스는 기존 --n900/--n50 토큰을 그대로 재사용(신규 색상 변수 없음) — 라이트 모드에서는 검정 배경+흰 텍스트, 다크 모드에서는 CSS 변수가 자동으로 뒤집혀 흰 배경+검정 텍스트가 되는데, 이게 마침 Apple 자체 가이드라인이 권장하는 "라이트 화면엔 검정 버튼, 다크 화면엔 흰 버튼" 규칙과 일치합니다. 다른 3개 버튼(네이버·카카오·Google)과 마찬가지로 아이콘 없이 텍스트만 사용(이 목업은 각 제공자 로고를 정확히 그리지 않는 기존 관례를 따름 — 실제 구현 시 각 SDK가 제공하는 공식 버튼 컴포넌트 사용 권장, 특히 Apple은 App Store 심사에서 버튼 디자인 규정 준수 여부를 실제로 확인함). 버튼이 3개→4개로 늘고 하단 링크가 없어진 만큼 버튼 간 여백을 10px로 통일했습니다. 1차 작업에서 마지막 버튼(Google)의 하단 여백을 22px→0으로 줄였는데, 사용자가 "Google로 시작하기가 너무 아래로 밀리지 않았냐"고 지적 — 실측해보니 위아래 flex:0.9 스페이서 자체는 정확히 동일(144px=144px)했지만, .screen의 padding이 상단만 10px이고 하단은 0px인 데다 마지막 버튼 여백까지 0으로 줘서 Google 버튼 밑단이 폰 프레임 안쪽 곡면에 거의 닿아있었습니다(프레임 하단과 간격 1px). 마지막 버튼 하단 여백을 0→20px로 재조정(이 문서의 토스트 컴포넌트가 쓰는 기본 하단 오프셋 20px과 동일 값 재사용)해 프레임 하단과의 간격을 21px로 확보, 라이트·다크 각각 스크린샷으로 재확인했습니다. <div> 태그 균형 변경 없음(1992=1992, 버튼 1개 제거+1개 추가로 상쇄).
v1.19 변경 이력 (2026-09-09) — 로그인 버튼 4개(Apple/네이버/카카오/Google) 스타일을 .btn-fill 하나로 통일했습니다. 사용자가 "Apple만 다른 색이면 이상하니 다 통일하거나 실제 브랜드 아이콘 로우로 바꾸자"고 제안했고, 브랜드 로고 원형 아이콘 방향(참고 이미지 첨부)도 검토했으나 — 구글·카카오는 공식 에셋(ZIP/PNG)이 실제로 존재하지만 네이버는 개발자센터 콘솔(앱 등록 필요) 접근이 있어야 받을 수 있고, Apple은 로고 자체를 버튼 컴포넌트 밖에서 쓰는 게 상표 가이드라인 위반이라 5개 제공자의 에셋 신뢰도가 서로 달라 이번엔 텍스트 버튼 통일로 결정했습니다. 기존 .btn-apple 클래스(v1.18에서 추가, --n900/--n50 토큰 재사용)는 더 이상 쓰이지 않아 CSS에서 제거했습니다. 버튼 순서(Apple → 네이버 → 카카오 → Google)와 여백(10px×3, 마지막 20px)은 v1.18 그대로 유지 — App Store 4.8 가이드라인상 Apple 버튼이 다른 소셜 로그인과 최소 동일한 노출도를 가져야 하는데, 스타일이 완전히 동일해졌으니 이 조건은 자연히 충족됩니다. <div> 태그 균형 변경 없음(1992=1992, 클래스 속성값만 교체).
