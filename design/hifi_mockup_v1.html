📱 독서 기록 공유 앱 — Hi-Fi 목업 v1

화면설계서(wireframe v2-5)의 프레임 구조를 그대로 따라가면서, 디자인 시스템 v1(컬러/타이포/아이콘)을 실제로 입힌 시안입니다.

Ver 1.3 375 × 812 (iPhone 기준) High-fidelity Mockup 작성일 2026-07-21
이 문서와 와이어프레임의 관계 — 화면 구조·문구·플로우는 화면설계서_wireframe_v2-5.html과 동일합니다 (프레임 번호도 그대로 대응). 이 문서는 그 구조 위에 실제 컬러 팔레트·Pretendard·Lucide 아이콘만 입힌 것으로, 기능 스펙에 대한 상세 설명(각 요소 번호별 주석)은 원본 와이어프레임을 참고해주세요. 여기서는 시각적으로 어떻게 보이는지에만 집중합니다.
v1.1 변경 이력 (2026-07-21) — 각 프레임 오른쪽에 다크모드 짝을 나란히 배치했습니다. 별도 파일이 아니라 같은 프레임 안에서 라이트/다크를 바로 비교할 수 있도록 CSS 변수 스코프(.dark)로 컬러만 전환하는 방식입니다 (마크업은 완전히 동일).
v1.2 변경 이력 (2026-07-21) — 프라이머리 그린이 칙칙해 보인다는 피드백에 따라 색상환(hue)을 128°→140°로 옮겨 같은 밝기에서 낼 수 있는 채도를 최대치로 끌어올렸고, 카테고리 구분용 포인트 멀티컬러(코랄·시안·라벤더, 파스텔톤)를 추가해 관심분야 칩과 장르 비율 차트에 반영했습니다.
v1.3 변경 이력 (2026-07-21) — "안드로이드보다 아이폰 감성"으로 UI 톤을 조정했습니다: Dynamic Island · iOS 스타일 상태바 아이콘(신호/Wi-Fi/배터리) 추가, 폰 프레임 코너를 더 둥글게, 카드·버튼·탭바에서 딱딱한 테두리 대신 헤어라인 + 그림자로 전환, 하단 탭바에 반투명 블러 적용, 공유 범위 선택 UI를 안드로이드 라디오버튼 대신 iOS식 리스트+체크마크로 교체, 주요 CTA 버튼을 캡슐(pill) 형태로 변경했습니다.
