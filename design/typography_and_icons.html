1. 폰트 — Pretendard

한글+영문+숫자가 자연스럽게 어울리고, 토스·네이버·우아한형제들 등 국내 서비스에서 가장 널리 쓰이는 UI 폰트입니다. Variable Font라 굵기(100~900)를 하나의 파일로 다 지원해서 로딩도 효율적입니다.

SIL OFL 1.1 (오픈폰트 라이선스)

Pretendard

상업적 사용: 무료, 제한 없음 (앱/웹/인쇄/영상/임베딩 전부 포함)

가능: 수정·재배포 가능

유일한 제한: 폰트 파일 자체를 단독으로 판매하는 것만 금지

출처: 눈누 - Pretendard 라이선스 페이지

💡 지금 이 페이지는 CDN(jsdelivr)으로 폰트를 불러왔지만, 실제 앱 배포 시에는 폰트 파일을 프로젝트에 내려받아 직접 서빙하는 걸 추천드립니다 (외부 CDN 장애/속도에 영향받지 않도록) — npm i pretendard 로 설치하거나 GitHub 릴리즈에서 woff2 파일을 받아 프론트엔드 assets/fonts에 넣으면 됩니다.

3. 아이콘 — Lucide

가늘고 일관된 획(2px stroke)의 라인 아이콘 세트로, 우리 연두 컬러와 조합했을 때 과하지 않고 깔끔합니다. 1,700개 이상 아이콘을 무료로 제공하며, 독서 앱에 필요한 아이콘(책/별점/북마크/통계 등)이 다 있습니다.

ISC License

Lucide Icons

상업적 사용: 무료, 제한 없음

조건: 라이선스 고지 문구 보존 (배포물에 라이선스 파일 포함 정도로 충분, 아이콘 하나하나에 표기 불필요)

형태: SVG로 제공 — 이 페이지에도 실제 SVG를 그대로 가져와 썼습니다

출처: Lucide 공식 라이선스 페이지
